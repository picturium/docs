`filter=` applies one or more effects. Separate them with `|`. They run left to right,
so the order can change the result.

```text
/photo.jpg?filter=brightness:1.1|contrast:1.2|blur:2
```

## The filter parameter

Each part is a filter name, a colon, and a value. Names aren't case-sensitive. An unknown
name, a missing colon, or a value that doesn't parse or is out of range makes the whole
request invalid.

Brightness, contrast and saturation have no upper limit, but anything between `0` and
`5` covers what most images need.

## Tone & colour

`brightness`, `contrast` and `saturate` leave the image alone at `1`. `hue` is in
degrees. Mix them when one adjustment isn't enough:

```text
/photo.jpg?filter=brightness:1.08|contrast:1.15|saturate:0.85
/photo.jpg?filter=hue:90|saturate:1.25
```

These don't touch the alpha channel. On grayscale images, `saturate` and `hue` have no
colour to work with and do nothing.

## Grayscale, sepia & invert

These take an amount between `0` and `1`, not an on/off switch. `0` does nothing, `1`
applies the full effect, and anything in between blends the two.

```text
/photo.jpg?filter=grayscale:1
/photo.jpg?filter=sepia:0.65|contrast:1.1
/photo.jpg?filter=invert:0.5
```

## Blur, sharpen & pixelate

`blur` and `pixelate` want whole numbers. `sharpen` takes a decimal up to `10`.

```text
/photo.jpg?w=900&filter=blur:3
/photo.jpg?filter=sharpen:1.5
/photo.jpg?w=800&h=600&filter=pixelate:12
```

Pixelate renders the image smaller by its factor, then scales it back up to the
requested size with nearest-neighbour. That means the block size depends on the final
dimensions from [Sizing & layout](/docs/sizing).

## Palette

One colour gives you a monochrome tint, two give a duotone. In a duotone, the first
colour is used for the highlights and the second for the shadows. An optional number at
the end sets the intensity: `1` by default, `0` for no effect.

```text
# Monochrome
/photo.jpg?filter=palette:ff8a1f

# Duotone: light, dark
/photo.jpg?filter=palette:ffd633,16181f

# Duotone at 70% intensity
/photo.jpg?filter=palette:ffd633,16181f,0.7
```

Colours use the same syntax as `bg`, but since commas separate the palette values,
stick to hex, colour names, or colour functions written with spaces (`rgb(255%20138%2031)`
once URL-encoded). `rgb(255,138,31)` would be split apart.

## Order & processing

Filters run after rotation, [cropping](/docs/cropping), resizing, fitting and padding,
and before the [watermark](/docs/watermarking) is drawn. Each filter works on the output
of the one before it:

Filters apply to every frame of an [animated image or video clip](/docs/animation).
Blur, sharpen and pixelate run frame by frame so neighbouring frames don't bleed into each
other. Filters are skipped when picturium returns the original file or a document with
[`f=pdf` or `f=svg`](/docs/output#format-selection).
